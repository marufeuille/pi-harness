# モデルをバージョンまで指定できるようにする

設定のモデル名を、`astra` や `grok` のような別名だけにしない。プロバイダとモデル ID をそのまま書けるようにする。バージョンの違いはモデル ID の違いとして選べる。

## 現状

`src/harness/models.ts` の4つの別名が、プロバイダ、モデル ID、思考レベルを固定している。別名にないバージョンは設定から選べない。

## 入出力

- 設定の `models.smart` と `models.cheap` は、プロバイダとモデル ID を持つ。
- 思考レベルを省略したときは、そのモデルが使える既定のレベルにする。
- 存在しないモデル ID は、実行前に理由を返して止める。

## 受け入れ

- 同じプロバイダの別バージョンを、コードを変えずに設定だけで切り替えられる。
- いまの `astra` / `luna` / `grok` / `fable` と同じモデルを、モデル ID を書いて指定しても動く。
