# Linear の課題をチケットとして取り込む

指定した Linear の課題 1 件を、いまの Markdown チケットと同じ入口でワークフローに渡せるようにする。

## 入出力

- 入力は Linear の課題 ID または URL。Markdown ファイルを直接渡す道は残す。
- ワークフローに渡る中身は、課題のタイトルと本文。課題に書いていない実装手順は補わない。
- 課題が取れない、または本文が空のときは、実装を始めずに理由を返す。

## 受け入れ

- 存在する課題 1 件を渡すと、要件確認から先は Markdown チケットのときと同じ順序で進む。
- 認証情報はリポジトリに入らない。
- マージ後の Linear 起票は、このチケットの範囲外。
